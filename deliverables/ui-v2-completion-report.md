### 🌳 品牌组件：Echo 情绪果实树

**文件**：`src/components/common/EchoLogo.tsx`

**规格**：
- 简约线条风果树 SVG（手绘感）
- 树干：奶棕色 `#A67C52`
- 果实：14 颗马卡龙圆形（粉/紫/蓝/黄/绿/橙随机分布）
- 文字："Echo" 衬线体 Georgia italic
- 支持 3 种尺寸：sm(120x96) / lg(200x160) / xl(280x220)
- 可选动画：果实摇摆 `animate-fruit-sway`

**使用场景**：
1. 导航栏品牌标识（size="sm"）
2. 欢迎页主视觉（size="lg"）
3. 我的角落页主视觉（size="xl", animated=true）
4. 侧边栏空状态 / 底部品牌
